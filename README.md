# Pastry for Mac

Pastry is a fast, private clipboard history for your Mac from [Birchtree Productions](https://birchtree.productions/apps/pastry/).

**[Download Pastry](https://github.com/mattbirchler/Pastry-releases/releases/latest/download/Pastry.dmg)** (macOS 26 or later, Apple silicon). It's free with your five newest items; buy it once or subscribe yearly on [the Pastry page](https://birchtree.productions/apps/pastry/) to unlock everything.

This repository holds Pastry's releases and its update feed (`appcast.xml`), which copies of Pastry check once a day. The source code is not here.
